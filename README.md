# ForgeQE Certification

The public study site for the ForgeQE certification: lessons, ForgeQE's guide, practice exams, the hands-on lab and
capstone guides, and a preview of the certification platform's pages.

Published at https://forgeqecertification.github.io.

These files are built; do not edit them here. They come from a private repository, which also holds the exam questions
and answers, and every publish is checked first so that no exam question, answer, hidden lab check, assignable capstone
brief or reviewer note is in them.
